# c-multithreaded-tcp-chat  

**Все сокеты работают в блокирующем режиме. Только IPv4**

В server.c основной поток устанавливает соединение с новыми клиентами и для каждого соединения создает новый поток, передавая туда файловый дескриптор полученного сокета. В этих новых потоках сервер получает сообщения от клиентов и рассылает их всем остальным клиентам.  

В client.c используется два потока. Основной поток читает сообщения клиента из консоли и отправляет их серверу. Второй поток получает сообщения от сервера и выводит их в консоль.  

---
Скомпилировать два файла можно так: `gcc client.c -o client -pthread`, `gcc server.c -o server -pthread`.   

В файле client.c нужно изменить константу SERVER_IP (вместо адреса 192.168.0.14 поставить адрес интерфейса компьютера, на котором запускается server.c).   
client.c можно запустить на том же сервере или на другом пк в одной с ним сети (192.168.0.0/24 в моем случае).
